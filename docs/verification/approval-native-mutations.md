### Playwright readiness fixtures (resolved)

`agent-runtime.spec.ts` 931, 971, 1019, 1060, 1160, 1294 and `workflows.spec.ts` 1629, 1692 previously timed out clicking a disabled **Approve** button (`disabled={!approval.readyForApproval}` in `approval-card.tsx`) because their fixtures seeded approvals without readiness evidence. The fixtures (`seedApproval`, `seedWorkflowApproval`) now call the test-only mock hook `__LINKGO_SQL_SEED_APPROVAL_READINESS__` in `tests/helpers/tauri-mocks.ts`. It seeds, at the variant's current `content_revision`, the four deterministic `draft_audits` rules, a completed AI audit run with the six canonical non-blocking findings, and a passed quality run (score 80). It creates no agent runs and throws if the variant is still not approval-ready. App code and the disabled condition are unchanged, so these tests now reach `linkgo_approval_set_status` and verify approve → continuation and workflow resume end to end.

`workflows.spec.ts:1722` (rejection `step_blocked` projection) passes through the new native mock.
